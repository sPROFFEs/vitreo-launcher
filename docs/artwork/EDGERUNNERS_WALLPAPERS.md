# Edgerunners character wallpapers

Four original fan-inspired illustrations generated for Vitreo with the built-in `image_gen` tool on 2026-11-09. They are not official promotional images or extracted game/series assets. Character names and Cyberpunk / Edgerunners belong to their respective owners; Vitreo is unaffiliated. Distribution of these new artwork files follows this repository’s MIT license.

The generated PNGs were inspected and encoded as WebP (quality 91) without creative retouching. All four final files are bundled in `app/src/main/res/drawable-nodpi/` and need no download.

Colors-only selection preserves the current photo, wallpaper, dim and effects. The explicitly labeled complete-style action applies the character palette and both Home / Lock collection wallpapers; it leaves activation, authentication, motion and effect preferences alone. Existing wallpaper/faction IDs are unchanged.

Reference: [official Edgerunners character material](https://www.cyberpunk.net/en/edgerunners). These variants interpret the characters’ visual palettes rather than copying screenshots.

## Final prompt set

Mode: built-in image generation, one new opaque portrait image per prompt. No external API key or CLI fallback.
